# Perbaikan audit copywriting Awan Event

Semua 11 temuan pada audit-001-2026-10-13.md ditangani pada source lokal. Teks CMS dan data event yang tersimpan di Supabase belum diperiksa atau diubah. Tidak ada deployment, pengiriman pesan, transaksi pembayaran, atau perubahan database jarak jauh.

## Perubahan

1. Angka 100+ dan kartu alumni di hero dihapus karena belum memiliki sumber terverifikasi.
2. Persyaratan sertifikat memakai requiredActivities sesuai tes yang aktif. Panel, nextAction, tautan aktivitas, jumlah aktivitas, dan daftar sertifikat membedakan event tanpa sertifikat, persyaratan belum lengkap, belum terbit, terbit, dan dicabut.
3. Operasi komunikasi berlabel Draf pesan, Tambah draf pesan, dan Simpan draf. Status Queued tetap dipertahankan untuk kompatibilitas data, tetapi ditampilkan sebagai Draf tersimpan. Pesan menjelaskan bahwa pengiriman belum tersedia; jadwal disebut rencana pengiriman.
4. Pencarian admin dan daftar event peserta memiliki pesan tanpa hasil dan tombol Hapus pencarian. Riwayat tanpa event selesai memiliki pesan tersendiri. Loading dan error data tidak disajikan sebagai data kosong.
5. Judul hero menyebut webinar, seminar, dan pelatihan kesehatan. Deskripsi menyebut tenaga kesehatan dan institusi. Teks kartu menyebut isi layanan, bukan hasil abstrak. Slogan merek yang sudah ada dipertahankan.
6. Sapaan pengguna pada teks bawaan diseragamkan menjadi Anda. CTA institusi dan halaman sertifikat dipersingkat. Pesan error halaman tidak lagi menjamin data tidak berubah.
7. FAQ, aktivitas peserta, label bagian editor event, dan label status operasi menggunakan bahasa Indonesia. Nama platform, pre-test/post-test, identifier, dan enum internal dipertahankan.
8. authErrorMessage memetakan error akun ke bahasa Indonesia. Error provider yang tidak dikenali memakai pesan umum, bukan pesan internal mentah. Provider platform mengutamakan pesan API Indonesia daripada detail validasi mentah.
9. Formulir pembuatan dan penggantian sandi menampilkan batas 8 sampai 128 karakter sesuai input. Tautan kembali menyebut halaman masuk.
10. CTA hero Lihat event mendatang mengarah ke #event-list, sesuai judul bagian tujuan.
11. Em dash di copy UI, metadata, accessible name, pesan simpan, dan placeholder diganti. Komentar source bukan copy UI dan tidak diubah. Countdown memakai elipsis saat tanggal belum tersedia agar label tetap muat.

## Arah teks dan alasan

Bahasa Indonesia profesional dan ramah untuk tenaga kesehatan, peserta, serta pengelola institusi. Sapaan Anda konsisten dengan formulir publik. Judul menyebut layanan nyata agar pembaca memahami bidang program. Status dan CTA mengikuti tindakan yang tersedia agar peserta tidak mendapat janji sertifikat atau pengiriman yang belum terjadi.

Perubahan mengikuti identitas visual yang sudah ada. Warna, tipografi, ruang, dan animasi tidak didesain ulang. ENERGY 2 / RHYTHM 2 / MOTION 2 dipakai sebagai pembacaan antarmuka terang dengan hero animasi yang sudah ada, bukan klaim audit visual menyeluruh. Tidak ada logo, profil orang, navigasi baru, statistik, atau testimoni yang dibuat.

## Validasi

- TypeScript: npx tsc --noEmit --pretty false lulus setelah perubahan.
- Lint: npm run lint lulus. Tiga peringatan img yang sudah ada pada ticket-code, professional-speakers, dan articles tetap tercatat.
- Build produksi lulus dan menghasilkan 49 halaman. Cache .next sebelumnya menimbulkan EINVAL/readlink di direktori OneDrive; build diverifikasi menggunakan distDir .next-copy-audit sementara. next.config.mjs dan penambahan include tsconfig dari Next dikembalikan setelah QA. Output sementara disimpan; cache lama tidak dihapus.
- Browser halaman hasil build: tmp/verify-copy-public.cjs lulus pada 1440 px dan 375 px. Platform snapshot memakai fixture kosong. Tidak ada login, remote write, atau pengujian pembayaran.
- Browser komponen: tmp/verify-copy-audit.cjs lulus menggunakan source komponen yang ditranspilasi dalam harness terisolasi. Provider, autentikasi, komponen Next, serta ikon diganti stub khusus pengujian; state dan interaksi React tetap dijalankan. Screenshot fixture tidak dipakai sebagai bukti layout production.

## Bukti klik dan state

- Lihat event mendatang menuju #event-list; Kenali Awan Event menuju #tentang.
- Jeda animasi dan Lanjutkan animasi mengubah state hero.
- Semua pertanyaan FAQ dibuka dan ditutup dengan Enter setelah fokus keyboard.
- Tampilkan/Sembunyikan kata sandi mengubah tipe input di halaman hasil build dan fixture.
- Buat akun pada fixture dengan error provider tidak dikenal menampilkan pesan Indonesia tanpa teks internal provider.
- Simpan kata sandi pada fixture dengan error provider menampilkan pesan Indonesia.
- Hapus pencarian mengosongkan kueri dan mengembalikan hasil event/admin.
- Riwayat tanpa event selesai menampilkan Belum ada event yang selesai.
- Tambah draf pesan membuka formulir; Simpan draf menutup formulir dan menampilkan Draf tersimpan. Status data tetap Queued; tidak ada email dikirim.
- Loading operasi menampilkan Memuat data; error menampilkan pesan dan tombol Coba lagi yang memanggil refresh fixture.
- Sertifikat dengan tes nonaktif menampilkan dua aktivitas; tes aktif menampilkan pre-test/post-test. Event tanpa sertifikat, belum terbit, terbit, dan dicabut diuji. nextAction mengikuti keadaan itu.
- Error pembatasan permintaan dan jaringan diuji terpisah agar pesan pemulihan sesuai penyebab.
